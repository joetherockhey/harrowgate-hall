# The Harrowgate Hall Affair

A three-stage murder mystery for two detectives. New Year's Eve, 1930.

**Play:** https://joetherockhey.github.io/harrowgate-hall/

Later stages are encrypted with the previous answer, so there are no spoilers in the source.

**Sample case:** https://joetherockhey.github.io/harrowgate-hall/example.html (a short, separate mystery showing the format)
